# Критерии бета-версии и разрешение на прошивку

Статус: **НЕ ГОТОВО К ПРОШИВКЕ**. Одиночные успешные тесты не обеспечивают безопасность Android.

- [ ] Автоматическая сборка из чистого клона с фиксацией версий компилятора и хешей EXE
- [ ] Матрица ext4: 16/64/256 МиБ, блоки 1/2/4 КиБ, стандартные ext4 features
- [ ] Бинарный round-trip: NUL, CR/LF/CRLF, 1 байт, файлы размером несколько блоков, несколько мегабайт
- [ ] Проверка контрольных сумм и состояния ФС после записи
- [ ] Повреждения суперблока, inode, bitmap и тест ремонта **только на одноразовых копиях**
- [ ] Проверить изменение размеров без усечения и запись за границами ФС
- [ ] Независимая сверка результатов с Linux e2fsprogs на тестовых образах
- [ ] Автоматическая проверка PE imports и отсутствия сторонних DLL
- [ ] Отдельный тест ext4 `shared_blocks`: отказ от небезопасной записи / корректное разворачивание
- [ ] Чтение актуальных AVB/vbmeta и dm-verity настроек с телефона (без изменений)
- [ ] Резервные копии всех задействованных разделов и подтверждённый доступный fastboot/EDL rollback
- [ ] Проверка изменённого образа и процедура отката до прошивки

Действия `fastboot flash`, `adb remount`, `e2fsck -y` на оригиналах запрещены до закрытия этих пунктов.
