# Бета-кандидат: подтверждённые результаты и ограничения

Дата: 28 октября 2026 года. На ASHOT собраны четыре исполняемых файла из отдельно настроенного `build-clean`: `debugfs.exe`, `dumpe2fs.exe`, `e2fsck.exe`, `mke2fs.exe`. Все используют только системные Windows DLL.

**Результат:** пять автоматических тестовых наборов успешно завершились (`tools/run_beta_tests.cmd`, код 0). Проверены форматы ext4 с блоками 1/2/4 КиБ, размеры до 256 МиБ, бинарные файлы до 4 МиБ, обнаружение и исправление счётчика ссылок inode, восстановление суперблока, отсутствие изменения размеров образа.

**Отдельная защита:** `debugfs -w` отказывается работать с ext4, у которого установлен `shared_blocks`. Тест создаёт одноразовый образ и устанавливает этот бит в суперблоке; проверены сообщение об отказе и неизменность SHA-256. Это тест отказа от записи, **не** проверка корректного редактирования настоящих дедуплицированных Android-разделов. `e2fsck -y` на `shared_blocks` не сертифицирован.

## Не завершено
- Независимая базовая Windows-проверка выполнена для файлов в корневом каталоге с extents глубины 0; дополнительные структуры ext4 ещё не покрыты.
- Полная upstream-сборка `make`: не портирован `tune2fs`, хотя четыре целевые утилиты собраны.
- CI в чистой среде/на другом компьютере, тесты больших ext4-образов, реальных дедуплицированных разделов и аварийного прерывания записи.


## Windows-only: обновление
Шесть наборов тестов PASS, включая независимый Python stdlib парсер для 1/2/4 КиБ блоков. Linux/WSL не требуется. См. WINDOWS_ONLY.ru.md.
