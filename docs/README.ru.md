# E2FSPROGS для Windows (экспериментальный порт)

Нативные утилиты Windows x64 на базе **e2fsprogs 1.47.3**, собранные MinGW-w64 со статической линковкой сторонних runtime-библиотек.

## Назначение
- `debugfs.exe`: просмотр структуры ext2/3/4, извлечение файлов; запись — только в тестовые копии.
- `dumpe2fs.exe`: просмотр метаданных и суперблока.
- `e2fsck.exe`: проверка ext2/3/4; режим `-fn` выполняется без исправлений.
- `mke2fs.exe`: экспериментальная утилита создания ext4; не входит в альфа-релиз.

## Установка
Архив предварительного выпуска: https://github.com/rokkystudio/E2FSPROGS/releases/tag/v0.1.0-alpha.1
Распакуйте архив в отдельную папку. Для запуска не нужны MSYS2/Cygwin DLL, но требуются системные компоненты Windows. Не помещайте EXE на системный PATH без необходимости.

## Безопасные примеры
```bat
dumpe2fs.exe -h C:\images\test.img
debugfs.exe -R "stat /path/to/file" C:\images\test.img
e2fsck.exe -fn C:\images\test.img
```
**Никогда не запускайте `e2fsck -y` или `debugfs -w` на единственном экземпляре данных.** Сначала сохраните образ и его SHA-256.

## Проверка и сборка
`python tests/test_native_ext4.py` — одноразовый образ ext4, запись/чтение и проверка повреждений; исполняемые файлы берутся из `artifacts/`, а `mke2fs.exe` из `build-local/misc/`. Сборка из чистого checkout пока не автоматизирована: часть созданных Autoconf Makefile дорабатывалась вручную. Исходники upstream закреплены Git-подмодулем, изменения — в `patches/windows-port.patch`. `git clone --recurse-submodules`.
